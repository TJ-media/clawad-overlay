# Claw-Ad Overlay v0.2.17

## 변경 사항
- 작업을 시작하면 `work-state` 변경을 즉시 감지해 광고를 함께 표시하고, 작업이 끝나면 유휴 유예시간 없이 광고를 함께 숨깁니다 (CLAW-287).
- 광고 캐시가 비어 있으면 다음 주기까지 기다리지 않고 즉시 동기화를 요청하며, 준비 중임을 화면에 안내합니다.
- Windows 최상단 순서를 광고 → 애드워드 → 입력창 순으로 다시 맞춰, 다른 앱의 최상단 창보다 광고를 위에 두면서 애드워드는 광고보다 앞에 유지합니다.

## 안정성 및 개인정보
- 렌더러가 실제로 그린 뒤 보낸 paint ACK부터만 표시 구간을 기록합니다. ACK timeout, 렌더러 종료, DWM cloak 상태는 창을 재생성해 복구합니다.
- 폐기된 광고창에서 늦게 도착한 오류 이벤트가 새 광고창을 닫지 못하게 창별 복구 범위를 고정했습니다.
- 로드 실패 로그에는 오류 설명이나 `file://` 로컬 경로를 남기지 않고 숫자 오류 분류만 기록합니다.

## 검증
- CLAW-287 관련 단위 테스트 135개가 통과했습니다. 작업 시작·종료 gate, paint ACK, 빈 캐시 sync, stale window 이벤트, Windows z-order와 fullscreen stand-down을 포함합니다.
- 전체 스위트는 5,527개 중 5,486개 통과, 기존 기준선과 같은 22개 실패, 19개 제외입니다.
- Electron·네이티브 의존성을 올리지 않았으므로 `runtimeId`는 v0.2.16과 같습니다. 기존 사용자는 경량 코드 업데이트 경로를 사용할 수 있습니다 (CLAW-161).

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다 (CLAW-95).
- 자동 테스트는 실제 타사 최상단 창의 OS z-order를 재현하지 않습니다. Windows 패키지에서 카카오톡 최상단 창과 함께 확인해야 합니다.
