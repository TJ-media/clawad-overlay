# Claw-Ad Overlay v0.2.9

## 변경 사항
- **미니 모드에서 마우스를 올리면 애드워드가 붙어 있던 자세 그대로에서 조금 더 나옵니다.** 0.2.8까지는 벽 뒤로 통째로 숨었다가 처음부터 다시 기어 나왔습니다. 이제 0.2초 동안 미끄러져 나오고 그대로 멈춥니다. (CLAW-242)
- 호버한 것을 알아채는 표현은 눈썹 올림과 빠른 더듬이 흔들림으로 남겼습니다.
- 미니 빼꼼 자세에 빠져 있던 그림자를 넣었습니다. 이전에는 대기 자세로 돌아갈 때 그림자가 튀어 들어왔습니다.

## 검증
- 미니 빼꼼과 미니 대기의 그림 차이가 눈썹·더듬이 네 줄뿐입니다. 몸 위치가 같아 상태가 바뀔 때 튀지 않습니다.
- `runtimeId`가 0.2.8과 같습니다. Electron·네이티브 의존성을 올리지 않았습니다. (CLAW-161)

## 알려진 제한
- macOS에서 `app.asar`만 갈아끼우는 경량 갱신 경로를 타면 이번 테마 변경이 반영되지 않습니다. 테마 파일은 `app.asar` 바깥(`app.asar.unpacked`)에 있습니다. Windows는 항상 전체 교체라 영향이 없습니다.
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
