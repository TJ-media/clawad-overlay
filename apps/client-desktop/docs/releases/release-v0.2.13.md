# Claw-Ad Overlay v0.2.13

## 변경 사항
- **macOS 사용자에게 마스코트 테마 변경이 실제로 전달됩니다.** 0.2.12까지는 경량 갱신이 `app.asar`만 교체했는데, 번들 테마·훅·에이전트·확장은 `app.asar.unpacked/`에 있어서 asar 안에 없습니다. 그래서 0.2.12의 마스코트 흰 테두리 수정이 경량 경로를 탄 macOS 사용자에게 닿지 않았습니다. 이제 asar 밖 트리 묶음(`app-<버전>-<arch>.unpacked.tar.gz`)을 함께 게시하고 갱신이 그것까지 교체합니다.
- **이 릴리스가 0.2.12에서 옛 테마에 묶인 macOS 설치본을 복구합니다.** 갱신하면 흰 테두리가 사라진 마스코트가 반영됩니다.
- 경량 갱신 크기는 7.2MB에서 7.8MB가 됩니다. 묶음에는 `node_modules`를 담지 않습니다 — 87MB 네이티브 트리는 의존성이 바뀔 때만 바뀌고, 그 판정은 `runtimeId`가 이미 하고 있습니다.

## 검증
- 매니페스트 규약 테스트 17건 통과(신규 3건). asar만 있고 묶음이 없으면 매니페스트 생성이 실패하도록 못 박았습니다 — 조용히 전체 교체로 되돌아가는 것을 막습니다.
- 전체 테스트 5460건 통과, 기존 실패 21건과 비교해 신규 실패가 없습니다.
- Electron·네이티브 의존성을 올리지 않았으므로 `runtimeId`는 0.2.12와 같습니다. (CLAW-161)

## 알려진 제한
- Windows는 이 경로를 쓰지 않습니다. 오버레이가 자체 업데이터로 설치본 전체를 갈아 asar 밖 트리도 함께 바뀝니다 — 0.2.12에서도 영향이 없었습니다.
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
- 실기기 스모크 체크리스트(`docs/project/release-process.md`)는 이번 릴리스에서 돌리지 않았습니다. 자동 테스트와 빌드 산출물 구성만 확인했습니다 — Windows·macOS 모두 실기기 미검증입니다.
