# Claw-Ad Overlay v0.2.7

## 변경 사항
- **미니 모드에서 마우스를 올리면 애드워드가 얼굴을 내밉니다.** 0.2.6까지는 벽 밖으로 큰 집게만 나왔습니다. 이제 바깥쪽 눈과 입 절반이 함께 나와 벽 모서리에서 빼꼼 내다보는 모습이 됩니다. (CLAW-240)
- 0.2.6에서 미니 크기를 바로잡으면서(CLAW-238) 펫이 벽 뒤로 덜 숨게 된 것이 원인이었습니다. 빼꼼 지점을 새 크기에 맞춰 다시 쟀습니다.

## 검증
- 창 200px 기준 빼꼼 극점에서 얼굴 17/35, 바깥쪽 눈 8/8, 입 7/14가 벽 밖으로 나옵니다 (이전 0/35, 0/8, 0/14).
- 숨는 지점은 그대로라 빼꼼 시작·끝에서는 여전히 완전히 가려집니다.
- `runtimeId`가 0.2.5·0.2.6과 같습니다. Electron·네이티브 의존성을 올리지 않았습니다. (CLAW-161)

## 알려진 제한
- macOS에서 `app.asar`만 갈아끼우는 경량 갱신 경로를 타면 이번 테마 변경이 반영되지 않습니다. 테마 파일은 `app.asar` 바깥(`app.asar.unpacked`)에 있습니다. Windows는 항상 전체 교체라 영향이 없습니다.
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
