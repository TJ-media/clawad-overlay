# Claw-Ad Overlay v0.2.6

## 변경 사항
- **벽에 붙는 미니 모드에서 마스코트가 제 크기로 보입니다.** 그동안 미니 모드에서만 캐릭터가 일반 상태의 약 2배로 확대되고 머리가 창 위로 잘렸습니다. 이제 벽에 붙어도 평소와 같은 크기·같은 바닥 기준선으로 그려집니다. (CLAW-238)
- 좌우 방향은 그대로입니다 — 왼쪽 벽에서는 원래 모습, 오른쪽 벽에서는 좌우가 뒤집힌 모습입니다.
- 미니 모드의 클릭 판정 영역도 함께 맞춰졌습니다. 이전에는 그림과 절반 배율로 어긋나 있었습니다.

## 검증
- 미니 8종의 그림 위치·크기가 일반 idle과 일치하는지 검증하는 테스트를 추가했습니다 (`test/clawad-mini-layout.test.js`). 예전 값으로 되돌아가면 266px 대 136px로 잡힙니다.
- `runtimeId`가 0.2.5와 같습니다. Electron·네이티브 의존성을 올리지 않았습니다. (CLAW-161)

## 알려진 제한
- macOS에서 `app.asar`만 갈아끼우는 경량 갱신 경로를 타면 이번 테마 변경이 반영되지 않습니다. 테마 파일은 `app.asar` 바깥(`app.asar.unpacked`)에 있습니다. Windows는 항상 전체 교체라 영향이 없습니다.
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
