## v0.1.3

광고 표시를 한 줄에서 두 줄로 나누고, 광고가 없을 때도 이 자리가 비지 않게 했다.

### 새 기능

- **광고를 2행으로 나눴다** (CLAW-138) — 한 줄에 전부 밀어 넣어 문구가 잘리고 적립 현황을
  보여줄 자리가 없던 것을 나눴다.

  - 1행 — `[광고]` 표기와 광고 문구
  - 2행 — 광고주와 적립 현황(오른쪽 정렬)

  적립 수치는 sync가 내려준 `reward-summary.json`의 값을 **그대로** 보여준다. 오버레이는
  포인트를 계산하지 않는다 — 노출당 단가는 서브 토큰 안에 있지만 열어보지 않는다. 확정 전
  값은 "예상"으로 표시한다.

  폭이 모자라면 광고주명이 먼저 줄어든다. 적립 수치를 자르면 `407P`가 `40…`으로 읽혀 금액을
  잘못 보여주게 되기 때문이다.

- **예상 포인트가 0.1씩 굴러 올라간다** (CLAW-138) — 값이 1 오를 때 숫자가 툭 튀지 않는다.
  표시 전용 보간이라 시작점도 끝점도 서버가 준 정수이고, 애니메이션이 끝나면 화면에는 서버
  값이 정확히 그대로 남는다. 첫 표시·감소·1을 넘는 점프는 굴리지 않고 바로 맞춘다.

- **누를 수 있는 광고는 문구에 밑줄이 생긴다** (CLAW-138) — ↗ 표식만으로는 눌리는지 알기
  어렵다는 피드백을 반영했다. 링크가 없는 광고에는 밑줄도 ↗도 없다.

- **광고가 없을 때 안내 문구를 보여준다** (CLAW-138) — 재고가 없어 빈 자리로 두던 구간에
  안내 문구를 15초마다 돌려 보여준다. 광고가 아니므로 `[광고]` 대신 `[안내]`가 붙는다.

- **미로그인 안내** (CLAW-138) — 로그인하지 않으면 광고를 받을 수 없으므로, 그 자리에 로그인
  안내를 띄운다. 누르면 로그인 흐름이 열린다. 클로애드 CLI가 설치돼 있지 않으면 누를 곳이
  없으므로 띄우지 않는다.

- **오늘 광고를 다 본 경우** (CLAW-138) — clawad가 소진 신호(`ad-inventory.json`)를 내려주면
  2행에 그 사실과 적립 현황을 함께 보여준다. **선택 항목이라** 신호를 보내지 않는 CLI와 함께
  써도 기존 동작을 그대로 유지한다.

### 그 밖

- 펫을 눌러 세션 목록이 열리면 광고가 비켜난다 (CLAW-138). 둘 다 펫 아래 같은 자리에 붙어서
  겹치는데, 사용자가 방금 눌러 띄운 쪽이 우선이다. 목록을 닫으면 바로 돌아온다.
- 광고 패널의 바깥 여백·좌우 여백을 세션 HUD와 같은 값으로 맞췄다. 테두리·라운드·그림자는
  원래 같았고, 여백까지 맞으면서 두 패널이 같은 자리에 같은 규격으로 앉는다.
