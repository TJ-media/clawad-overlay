# Claw-Ad Overlay v0.1.12

## 변경 사항
- 마스코트 테마를 v1.6.2로 갱신했습니다. 간지럼 리액션, 좌우 반전(`flipAssets`), 미니 모드 축소, 드래그 꼬리 표현이 반영됩니다. 이전까지 오버레이 번들은 v1.6.0에 멈춰 있어 원본 저장소의 테마 개선이 앱에 반영되지 않았습니다.
- 안내 문구가 길어도 창이 문구 길이에 맞게 넓어집니다. 로그인 전 처음 보이는 안내가 항상 말줄임되던 문제를 고쳤습니다. (CLAW-172)
- 사용자 데이터 폴더 이름에서 포크 원본 이름을 제거했습니다. 기존 폴더가 있으면 새 이름으로 자동 이전합니다. (CLAW-155)

## 원인
- 테마: 원본(비공개 저장소의 마스코트 소스)에서 빌드한 산출물을 오버레이 번들로 **수동 복사**하는 구조인데, v1.6.0 이후 복사가 이뤄지지 않았습니다.
- 안내 문구 폭: 광고 문구 기준으로만 폭을 계산해, 문구가 없는 안내 상태에서는 최소 폭이 적용됐습니다.
- userData 경로: 포크 시점의 앱 이름이 그대로 남아 사용자 폴더에 원본 제품명이 노출됐습니다.

## 검증
- 동기화 후 테마 파일이 원본과 바이트 단위로 일치함을 확인했습니다(`theme.json` v1.6.2, `fileViewBoxes` 포함).
- 안내 문구 폭 회귀 테스트를 추가했습니다.
- userData 이전은 대상 폴더가 이미 있고 비어 있지 않으면 아무것도 옮기지 않으며, 실패해도 앱 실행을 막지 않습니다. 이전 로직 단위 테스트를 추가했습니다.

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 Windows SmartScreen / macOS Gatekeeper 경고가 표시됩니다. (CLAW-95)
