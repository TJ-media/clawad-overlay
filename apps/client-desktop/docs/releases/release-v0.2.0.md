# Claw-Ad Overlay v0.2.0

## 변경 사항
- **클로애드 CLI와 버전 번호를 맞췄습니다.** 지금까지 CLI와 오버레이 번호가 따로 움직여, 오버레이 화면이 말하는 버전(`v0.1.14`)과 `clawad status`가 말하는 버전(`0.1.22`)이 달라 사용자가 자기 버전을 특정할 수 없었습니다. 이 릴리스부터 두 저장소를 항상 같은 번호로 자릅니다. (CLAW-214)
- 앱 동작 변경은 없습니다. 0.1.14와 기능이 같습니다.

## 검증
- `runtimeId`가 0.1.14와 같습니다 (`1665a5ea…`). Electron·의존성이 그대로라, 기존 사용자는 전체 번들이 아니라 `app.asar`만 받는 경량 경로로 갱신됩니다. (CLAW-161)

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
