# Claw-Ad Overlay v0.2.12

## 변경 사항
- **마스코트 흰 테두리를 없앴습니다.** 번들 테마의 파츠 이미지가 초기 도입 시점 그대로여서, 머리 위·다리 위·다리 옆·팔·꼬리·집게 가장자리에 잘린 흰 픽셀 줄이 남아 있었습니다. 원본 테마와 다시 맞췄습니다. 몸통 아래 흰 줄도 이번에 함께 지웠습니다.
- **게걸음 꼬리 잘림이 사라집니다.** 테마 캔버스가 `-60 0 780 760`에서 `-96 0 816 760`으로 넓어집니다. 게걸음이 몸통을 좌우 36px 옮기는 동안 꼬리가 캔버스 밖으로 나가 잘리던 구간이 들어옵니다. `objectScale`이 같은 비율로 함께 조정돼 **마스코트가 그려지는 크기와 클릭 영역은 그대로입니다.**
- **미니 모드(벽 부착)가 화면 맨 위까지 올라갑니다.** 화면 최상단에 붙인 마스코트는 창을 작업 영역 위쪽 끝에 두고 그림만 투명 여백만큼 위로 당겨 그립니다. 벽에 붙는 순간 이 보정을 0으로 되돌리면서 창은 그대로 둬서, 마스코트가 여백만큼 아래로 떨어졌습니다. 미니 모드에서는 드래그가 막혀 있어 되돌릴 방법이 없었고, 앱을 껐다 켜도 같은 만큼 다시 떨어졌습니다.

## 검증
- 미니 모드 회귀 테스트 3건을 새로 추가했습니다. 수정을 되돌리면 3건 모두 실패합니다.
- 전체 테스트 5457건 통과, 기존 실패 21건과 비교해 신규 실패가 없습니다.
- Electron·네이티브 의존성을 올리지 않았으므로 `runtimeId`는 0.2.11과 같습니다. 기존 사용자는 `app.asar`만 받습니다. (CLAW-161)

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
- 실기기 스모크 체크리스트(`docs/project/release-process.md`)는 이번 릴리스에서 돌리지 않았습니다. 자동 테스트와 빌드 산출물 구성만 확인했습니다 — Windows·macOS 모두 실기기 미검증입니다.
