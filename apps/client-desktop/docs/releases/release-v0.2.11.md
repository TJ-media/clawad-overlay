# Claw-Ad Overlay v0.2.11

## 변경 사항
- **로그인하지 않은 상태에서 로그인 안내판이 실제로 뜹니다.** 원인은 clawad CLI 쪽에 있었습니다 — sync가 오버레이 협약 파일(트리거 포인터·정책 캐시)을 인증 검사 뒤에 써서, 한 번도 로그인하지 않은 사용자에게는 두 파일이 영영 생기지 않았습니다. 그동안 로그인 진입점은 터미널 명령 하나뿐이었습니다.
- 로그인 안내를 띄우는 동안에는 트레이·마스코트 우클릭 메뉴에서 **안내 끄기**를 감춥니다. 로그인 안내는 끌 수 없는 화면이라, 눌러도 아무 것도 사라지지 않는 항목이 남지 않게 했습니다.
- 우클릭 메뉴의 **리워드샵 열기**를 **홈페이지 바로가기**로 바꿨습니다(지원 언어 5종). 홈페이지가 리워드샵보다 넓어졌습니다.

## 검증
- 광고 창·메뉴·인증 상태 회귀 테스트 77건을 통과했습니다.
- 전체 테스트의 기존 실패 22건과 비교해 신규 실패가 없습니다.
- Electron·네이티브 의존성을 올리지 않았으므로 `runtimeId`는 0.2.10과 같습니다. (CLAW-161)

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
