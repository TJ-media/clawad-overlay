# Claw-Ad Overlay v0.2.5

## 변경 사항
- **새로 설치하면 로그인 시 자동 실행으로 시작합니다.** 오버레이가 떠 있지 않으면 광고도 포인트 적립도 발생하지 않는데, 그동안은 재부팅 한 번에 조용히 멈췄습니다. (CLAW-228)
- 이미 쓰고 계신 분의 설정은 바꾸지 않습니다. 일부러 꺼 두셨다면 그대로 유지됩니다.
- 끄는 곳은 **설정 > 일반 > 로그인 시 자동 실행**입니다.
- 제거하면 등록한 자동 실행 항목도 함께 지웁니다.

## 검증
- `runtimeId`가 0.2.4와 같습니다. Electron·네이티브 의존성을 올리지 않았습니다. 기존 사용자는 `app.asar`만 받는 경량 경로로 갱신됩니다. (CLAW-161)
- 자동 실행 판단과 제거 정리에 테스트를 추가했습니다 (`test/menu-autostart.test.js`).

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
