## v0.1.8

광고판의 안내를 직접 제어하고 리워드샵으로 이동할 수 있으며, 긴 광고 문구와 적립 표시가 더 자연스러워졌다.

### 새 기능

- **안내 끄기와 다시 켜기** (CLAW-163) — 광고가 없는 시간에 표시되는 로컬 안내를 광고판에서 바로 끌 수 있다.
  트레이와 펫 우클릭 메뉴에서 언제든 다시 켤 수 있으며 광고 표시·적립 설정과는 분리된다.
- **리워드샵 열기** (CLAW-166) — 트레이와 펫 우클릭 메뉴에서 클로애드 리워드샵을 기본 브라우저로 연다.
  주소는 CLI 정책 캐시가 전달하는 HTTPS 값만 사용하고 클릭 사실은 수집하지 않는다.

### 개선

- **긴 광고 문구를 두 줄까지 표시** (CLAW-162) — 창 너비 계산에 패널 여백을 포함해 불필요한 말줄임을 줄였다.
- **예상 적립 표시를 부드럽게 갱신** (CLAW-165) — 서버가 내려준 적립 총액까지 갱신 간격 전체에 걸쳐 자연스럽게
  움직이고, 총액이 있을 때 중복되는 확정 표기를 제거했다.

### 알려진 사항

- 무서명 알파 빌드다. 코드서명·공증은 CLAW-95에서 별도로 진행한다.
- macOS와 Linux 실기기 검증은 이번 자동 릴리즈에서 수행하지 않았다.
