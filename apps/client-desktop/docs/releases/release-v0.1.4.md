## v0.1.4

첫 실행에 macOS 키체인 암호를 묻던 문제를 없앴다. 원인이던 원격 SSH 기능을 통째로 걷어냈다.

### 고친 것

- **첫 실행에 키체인 암호를 묻지 않는다** (CLAW-154) — 설치 직후 앱을 켜면 macOS가
  "'clawd-on-desk Safe Storage'에 저장된 비밀 정보를 사용하려고 합니다"라며 로그인 키체인
  암호를 요구했다. 광고 표시와 무관한 원격 SSH 기능이 시작 시점에 Electron의 안전 저장소를
  건드린 탓이다. 그 경로를 제품에서 없앴다.

  "항상 허용"을 눌러도 업데이트할 때마다 다시 묻던 것도 함께 사라진다. 무서명 빌드는 서명이
  매번 달라지는데 키체인 권한이 서명에 묶여 있었다.

### 제거한 것

- **원격 SSH** (CLAW-140) — 원격 호스트에 훅을 배포하고 그 호스트의 상태를 받아오는 기능이다.
  포크 원본에서 딸려온 것으로 광고 매체 제품에 필요하지 않고, 외부 전송 부가 기능을 걷어낸
  CLAW-129와 같은 판단선에 있다. 설정의 "SSH Hosts" 탭이 사라진다.

  모듈 12개와 관련 테스트, 5개 언어의 문구 520여 개를 함께 제거했다. 18,000줄 규모다.

- **쓰지 않는 페이슈 SDK** — 기능은 CLAW-129에서 제거됐는데 의존성만 남아 배포 파일에 계속
  실려 있었다.

### 그 밖

- 세션 정리 설명 문구를 실제 동작에 맞게 고쳤다. "원격 SSH 세션에 적용됩니다"라고 안내하던
  것을 "터미널을 더 이상 찾을 수 없는 세션"으로 바꿨다. 기능 자체는 그대로다.
- 셸 인용 유틸(`remote-ssh-quote.js`)은 이름만 `shell-quote.js`로 바꿔 남겼다. 원격 SSH와
  무관한 범용 코드이고 "터미널로 이동" 기능이 쓴다.
- 원격 SSH와 키체인 접근이 되돌아오면 실패하는 회귀 검사를 넣었다.

### 알려진 사항

- 무서명 알파 빌드다. 코드서명·공증은 CLAW-95에서 따로 진행한다. 설치 시 Gatekeeper가 막으면
  시스템 설정 → 개인정보 보호 및 보안에서 허용한다.
