## v0.1.7

업데이트가 막히던 문제를 없애고, 앞으로 받을 용량을 크게 줄였다.

### 고친 것

- **업데이트하면 "확인할 수 없는 개발자" 경고로 앱이 안 열리던 문제** (CLAW-160) — 브라우저로 내려받은 앱에는
  macOS가 격리 표시를 붙이고, 서명이 없는 알파 빌드는 그 표시 때문에 실행이 막혔다. 이제 업데이트를 누르면
  브라우저를 열지 않고 **클로애드가 직접 내려받아 설치한다.** 표시가 붙지 않으므로 경고도 없다.

  잠시 종료됐다가 새 버전으로 다시 열린다. 실패해도 쓰던 버전이 그대로 남는다.

  클로애드 CLI가 없으면 예전처럼 다운로드 페이지를 연다.

### 달라진 것

- **업데이트 용량이 크게 줄어든다** (CLAW-161) — 이 앱은 358MB이지만 그중 우리 코드는 7MB뿐이다. 나머지는
  앱 실행 기반이라 그것을 올릴 때만 바뀐다. 코드만 바뀐 업데이트는 앞으로 **7MB만** 받는다.

  이번 업데이트는 아직 전부 받는다 — 기준값을 남기는 릴리스라 다음부터 줄어든다.

### 알려진 사항

- 무서명 알파 빌드다. 코드서명·공증은 CLAW-95에서 따로 진행한다.
- 이 버전으로 올라오는 것까지는 클로애드 CLI v0.1.16의 설치·업데이트를 쓰면 경고 없이 된다. 릴리스 페이지에서
  직접 내려받으면 여전히 격리 표시가 붙어 Gatekeeper 허용이 필요하다.
