## v0.1.6

macOS에서 업데이트를 받을 때 파일을 고르지 않아도 된다.

### 달라진 것

- **이 맥에 맞는 설치 파일을 바로 내려받는다** (CLAW-158) — 예전에는 "다운로드"를 누르면 GitHub 릴리스
  페이지가 열려서, 거기 올라온 파일 여러 개 중 자기 맥에 맞는 것(Apple Silicon용인지 Intel용인지)을
  직접 골라야 했다. 이제 누르면 맞는 파일 다운로드가 곧바로 시작된다.

  Rosetta로 실행 중이면 더 빠른 Apple Silicon용을 권한다.

  받은 파일을 열어 응용 프로그램 폴더로 옮기는 것은 여전히 직접 해야 한다. 무서명 빌드라 앱이 스스로
  교체할 수 없기 때문이다 — 코드서명을 받으면(CLAW-95) 윈도우처럼 자동으로 설치된다.

### 알려진 사항

- 무서명 알파 빌드다. 설치 시 Gatekeeper가 막으면 시스템 설정 → 개인정보 보호 및 보안에서 허용한다.
- **이 버전으로 올라오는 것까지는 손으로 받아야 한다.** 위 개선은 v0.1.6이 깔린 뒤 다음 업데이트부터
  적용된다.
