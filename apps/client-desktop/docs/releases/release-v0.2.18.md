# Claw-Ad Overlay v0.2.18

## 변경 사항

- 광고 문구가 두 줄에 들어가면 실제 내용에 맞춰 광고판을 좁힙니다. 광고주와 예상 적립이 왼쪽으로 이동해 첫 줄 오른쪽의 빈 공간이 줄어듭니다. (CLAW-291)
- 글자 배율을 줄인 경우에도 필요한 창 폭을 올림해 둘째 줄 끝이 잘리지 않게 했습니다.

## 검증

- macOS Chromium에서 재현 문구의 광고판이 420px에서 351px로 줄고 본문과 예상 적립이 모두 보이는 것을 확인했습니다. 문구, 광고주, 배율을 바꾼 1,650가지 조합에서 줄 잘림 회귀가 없었습니다.
- 광고판과 릴리스 매니페스트 관련 테스트에서 66건이 통과했고, 테스트 정의에 따라 1건을 건너뛰었습니다. 전체 스위트의 기존 실패 20건은 최신 develop 기준선과 같습니다.
