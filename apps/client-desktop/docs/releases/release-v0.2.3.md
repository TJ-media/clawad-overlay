# Claw-Ad Overlay v0.2.3

## 변경 사항
- 오버레이 코드 변경은 없습니다. 클라이언트 0.2.3과 **번호를 맞추기 위한 릴리스**입니다 (CLAW-214). 두 저장소가 사용자에게는 하나의 "클로애드 버전"으로 보여야 하고, 번호가 어긋나면 오버레이 화면이 말하는 버전과 `clawad status`가 말하는 버전이 달라집니다.
- 같은 번호의 클라이언트 릴리스에는 설치·업데이트 출력 정리(CLAW-220)와 격리 가드(CLAW-221)가 들어갔습니다.

## 검증
- `runtimeId`가 0.2.2와 같습니다. Electron·네이티브 의존성을 올리지 않았습니다. 기존 사용자는 `app.asar`만 받는 경량 경로로 갱신됩니다. (CLAW-161)

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
