# Claw-Ad Overlay v0.2.10

## 변경 사항
- **마스코트를 드래그할 때 광고판이 바로 아래를 실시간으로 따라옵니다.** 이전 버전에서는 광고 상태를 확인하는 1초 주기에 위치 갱신도 묶여 있어 광고판이 눈에 띄게 뒤처질 수 있었습니다. (CLAW-243)
- 광고뿐 아니라 재고 안내와 로그인 안내 패널도 같은 드래그 프레임에서 함께 이동합니다.
- 광고 내용 선택과 노출 구간을 관리하는 1초 주기는 유지하고, 창 위치 갱신만 기존 프레임 단위 재배치 경로로 분리했습니다.

## 검증
- 광고 창 재배치와 공통 앵커 배선 회귀 테스트 7건을 통과했습니다.
- 전체 테스트의 기존 실패 24건과 비교해 신규 실패가 없습니다.
- Electron·네이티브 의존성을 올리지 않았으므로 `runtimeId`는 0.2.9와 같습니다. (CLAW-161)

## 알려진 제한
- 패키지 설치본의 실제 드래그·다중 모니터 동작은 Windows/macOS 실기기에서 별도로 검증하지 않았습니다.
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
