# Claw-Ad Overlay v0.2.2

## 변경 사항
- **광고판 오른쪽에 빈칸이 남던 문제를 고쳤습니다 (CLAW-219).** 광고판 폭을 잴 때 적립 현황 자리(컷아웃)의 폭이 문구 폭에 더해져, 문구가 한 줄에 들어가는 광고에서 문구 오른쪽에 55~74px의 빈 공간이 남았습니다. macOS에서 보이던 증상입니다.

## 검증
- 실제 광고 문구로 계측: 창 폭 284 → 210, 422 → 367, 519 → 454px로 줄고 문구 뒤 빈칸이 0~1px이 됐습니다.
- 두 줄로 감기는 긴 문구는 영향이 없습니다. 둘째 줄은 그대로 적립 현황을 비켜 갑니다.
- `runtimeId`가 0.2.1과 같습니다. 기존 사용자는 `app.asar`만 받는 경량 경로로 갱신됩니다. (CLAW-161)

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
