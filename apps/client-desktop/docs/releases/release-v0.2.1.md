# Claw-Ad Overlay v0.2.1

## 변경 사항
- 클로애드 클라이언트 0.2.1과 번호를 맞춘 릴리스입니다. 앱 동작 변경은 없습니다. (CLAW-214)

## 검증
- `runtimeId`가 0.2.0과 같습니다. Electron·의존성이 그대로라 기존 사용자는 `app.asar`만 받는 경량 경로로 갱신됩니다. (CLAW-161)
- 클라이언트 0.2.1이 경량 갱신 후 번들 버전 표기를 고치므로, 이 릴리스부터 갱신이 한 번으로 끝납니다. (CLAW-216)

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
