## v0.1.2

광고가 주기적으로 멈추던 문제를 고쳤다. macOS 릴리스 산출물 생성 경로도 함께 들어갔다.

### 버그 수정

- **좀비 세션 때문에 광고가 주기적으로 멈추던 문제** (CLAW-142) — 훅이 `Stop`을 보내지 못한 세션은
  활동 상태가 `active: true`로 굳는다(터미널 강제 종료 등). 활성 판정이 경과 시간을 보지 않아
  **며칠 전 좀비 세션 하나로 "영원히 작업 중"** 이 됐고, 작업하지 않는 동안에도 광고를 계속
  돌려 받아둔 광고를 모두 소진한 뒤 표시가 완전히 멈췄다.

  실측(2026-07-30): 좀비 세션 2개(6일 전·23시간 전 시작), 45분간 광고 0건, 유효 재고 38건이
  그대로 남은 상태.

  이제 활성 판정이 clawad 수거측과 **같은 규칙**으로 오래된 활성 상태를 닫는다. 임계 안의 긴
  턴은 그대로 작업 중으로 인정한다.

- **인정되지 않은 광고가 재고를 영구히 소모하던 문제** (CLAW-142) — 화면에 뜨는 순간 소진
  처리했는데, 인정으로 이어지지 않은 광고는 CLI가 캐시에서 지우지 않고 서버도 "미사용"으로
  센다. 그래서 재고가 교착됐다 — 앱은 다시 쓰지 않고 서버는 새로 주지 않는다.

  이제 인정 요청까지 간 것만 소진 처리한다. 미달로 끝난 표시는 다시 쓸 수 있게 하되, 직전
  소재를 피하고 재시도 횟수에 상한을 둔다.

### 그 밖

- **macOS 릴리스 산출물과 워크플로** (CLAW-92) — 릴리스 매니페스트가 플랫폼·아키텍처별 산출물을
  담는다. 매니페스트는 `dist/`를 훑어 **실제로 있는 산출물만** 기록하므로, 이름을 추측해 조용히
  깨진 매니페스트가 나가지 않는다. 구버전 CLI 호환을 위해 `win32-x64`는 최상위에도 복제한다.
- 저장소 문서에 브랜치 전략(기능 → `develop` → `main`)과 검증 기준·함정을 기록했다.

### 호환성

- 이번 릴리스의 매니페스트에는 **Windows x64 산출물만** 담겨 있다. macOS 빌드는 별도 러너가
  필요하며, 없는 플랫폼은 CLI가 설치를 건너뛴다.
- 활동 상태 유효기간은 정책 캐시의 **선택 항목**이다. 이 값을 담기 시작한 CLI(0.1.13 이상)가
  아직 없어도 광고는 계속 표시되며, 기존 판정을 유지한다. 따라서 CLI와 이 앱의 릴리스 순서는
  무관하다.
