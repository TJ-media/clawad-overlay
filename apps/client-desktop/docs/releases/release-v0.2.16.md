# Claw-Ad Overlay v0.2.16

## 변경 사항
- **애드워드가 자유배회 중 실제로 걷습니다** (CLAW-286). 지금까지는 테마에 `roam` 상태가 없어 idle 그림(제자리 숨쉬기)에 3px짜리 좌우 흔들림만 얹힌 채 끌려다녔습니다. 전신 걸음 그림이 생겨 그 폴백은 자동으로 꺼집니다.
- **마우스로 애드워드 주위를 돌리면 어지러워합니다.** 한 방향으로 1.5바퀴를 2초 안에 돌면 나선 눈이 되고 머리 위로 별이 돕니다. 눈이 커서를 따라가는 기능이 이미 있어서, 눈이 따라 돌다 지친다는 인과가 화면에서 성립합니다.
- 원 그리기 판정을 2바퀴에서 1.5바퀴로 낮추고 2초 슬라이딩 창을 넣었습니다. 창이 없으면 아주 느린 드리프트가 1분에 걸쳐 한 바퀴로 쌓여 의도하지 않은 발동이 납니다.

## 검증
- 누적 규칙을 `src/spin-meter.js`로 분리하고 단위 테스트 9개를 붙였습니다 — 1.5바퀴 발동, 1.4바퀴 미발동, 좌우 흔들기 상쇄, 2초 초과 미발동, 최소 거리, 멈춤 리셋, 쿨다운.
- Electron·네이티브 의존성을 올리지 않았으므로 `runtimeId`는 0.2.15와 같습니다 — 기존 사용자는 전체 번들이 아니라 경량 경로를 탑니다 (CLAW-161).
- 매니페스트에 `codeUpdate.unpacked` 블록이 실려 나가는지 릴리스 산출물에서 확인합니다 (CLAW-283).

## 알려진 제한
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
- 실기기 스모크 체크리스트(`docs/project/release-process.md`)는 이번 릴리스에서 돌리지 않았습니다. 자동 테스트와 산출물 구성만 확인했습니다.
