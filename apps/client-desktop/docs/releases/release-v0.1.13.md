# Claw-Ad Overlay v0.1.13

## 변경 사항
- 업데이트 다운로드 알림에 진행바가 생겼습니다. 받는 만큼 막대가 차오르고 퍼센트를 함께 표시합니다. 제목과 본문에 같은 문구("업데이트 다운로드 중…")가 두 줄로 겹쳐 나오던 것도 없앴습니다. (CLAW-189)
- 광고판 둘째 줄에서 광고주와 구분점 사이를 한 칸 띄웠습니다. `와썹하우스· 예상 적립` → `와썹하우스 · 예상 적립`. (CLAW-190)

## 원인
- 알림: 다운로드 버블을 띄우는 쪽이 같은 문자열을 제목과 본문에 두 번 넘기고 있었고, 진행률을 표시하는 경로가 아예 없었습니다.
- 광고판: 구분점 앞 공백이 없었습니다. 일반 스페이스를 넣으면 인라인 내용의 맨 앞이라 공백 처리 규칙에 걸려 사라지므로 `nbsp`로 넣었습니다.

## 검증
- 진행바 실측(트랙 852px): 0%→0px, 25%→213px, 50%→425px, 100%→850px. 범위를 벗어난 값은 0~100으로 잘라내고, 진행률을 모르면 막대를 숨깁니다.
- 진행바 색: 트랙 흰색 + 얇은 테두리 + 그림자, 채움은 제품 기본색(`#d97757`). 다크 모드는 트랙 톤만 낮추고 채움 색은 동일합니다.
- 구분점 간격 실측: 공백 추가 전 84.69px → 후 90.71px.
- 관련 테스트 통과(업데이터 68 + 버블 20 + 광고판 81).

## 알려진 제한
- 다운로드 진행바는 Windows 경로에서 표시됩니다. macOS는 CLI에 위임하고 앱이 종료되는 구조라 표시되지 않습니다.
- 코드서명·공증이 아직 없는 알파 빌드입니다. 첫 실행 시 SmartScreen / Gatekeeper 경고가 표시됩니다. (CLAW-95)
