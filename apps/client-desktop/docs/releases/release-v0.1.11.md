# Claw-Ad Overlay v0.1.11

## 변경 사항
- 광고판의 `안내 끄기` 버튼, 마스코트 우클릭 메뉴의 `안내 끄기`·`광고 일시중지`가 실제로 동작합니다. 누르면 광고판이 즉시 사라지고, 선택은 재시작 후에도 유지됩니다. 이전에는 세 컨트롤 모두 아무 반응이 없었습니다. (CLAW-170)
- 안내 문구를 다듬었습니다: `작업하는 동안 광고가 표시되면 리워드가 적립돼요` → `작업하는 동안에만 광고가 표시되며 리워드가 적립돼요`. (CLAW-170)

## 원인
- 설정 쓰기 경로(`updateRegistry`)에 `clawadAdsPaused`·`clawadNoticesHidden` 항목이 없어 저장 요청이 `unknown settings key`로 거절됐습니다. 설정이 저장되지 않으니 표시를 내리는 코드가 아예 호출되지 않았습니다.
- 두 기능(광고 일시중지 CLAW-89, 안내 끄기 CLAW-163)은 도입된 시점부터 이 상태였습니다. 호출부가 저장 실패를 확인하지 않아 오류가 로그에도 남지 않았습니다.

## 검증
- 안내 표시 중 안내 끄기 → 같은 주기에 광고판이 숨는 것을 확인 (대기 없음)
- 광고 일시중지 → 광고 창이 정리되고 서피스 락이 반환되는 것을 확인
- 회귀 테스트 6건 추가. 수정 전 4건이 실패하는 것을 확인했습니다
- 설정 스키마의 모든 키가 쓰기 경로에 등록돼 있는지 검사하는 테스트를 추가해 같은 유형의 누락을 차단합니다
