# 광고주 소재·마스코트 실시간 미리보기 설계

- Jira: CLAW-244
- 후속 범위: CLAW-245
- 대상 저장소: `clawad-overlay` 단일 저장소
- 작성일: 2026-08-19

## 1. 목적과 범위

광고주가 광고 문구와 광고주명을 입력하면서 데스크톱 오버레이에서 보일 형태를 즉시 확인하는 독립 정적 페이지를 만든다. 페이지는 저장·로그인·서버 API 없이 브라우저 메모리에서만 동작한다. 운영 광고판 코드를 가져오거나 공용 모듈로 결합하지 않고, 같은 표시 규칙과 치수를 별도 미리보기 코드로 재현한다.

이번 범위는 `clawad-overlay` 저장소만 변경한다. 비공개 `clawad` 저장소, 캠페인 저장, 심사 제출, 과금·리워드 계산, 실제 노출 기록은 변경하지 않는다. 광고주 인증과 저장·심사 제출은 CLAW-245에서 다룬다.

## 2. 배치와 실행 방식

정적 페이지는 `apps/client-desktop/advertiser-preview/`에 둔다.

- `index.html`: Windows XP 스타일 창, 입력 폼, 실제 크기 미리보기, 마스코트 선택 목록
- `preview.css`: 페이지 디자인과 광고판 미리보기 전용 스타일
- `preview-model.js`: 입력 정화, 길이 제한, 마스코트 목록을 제공하는 브라우저·Node 겸용 순수 모듈
- `preview.js`: DOM 이벤트 연결과 화면 갱신만 담당하는 얇은 컨트롤러

페이지는 별도 빌드 없이 `index.html`을 직접 열어 동작한다. 모든 스크립트와 스타일은 상대 경로의 로컬 파일이며, 마스코트는 `../themes/clawad/assets/`의 기존 에셋을 직접 참조한다. `fetch`, XHR, WebSocket, `sendBeacon`, 쿠키, `localStorage`, `sessionStorage`를 사용하지 않는다.

`apps/client-desktop/.gitignore`가 허용목록 방식이므로 `advertiser-preview/**`를 명시적으로 추적 허용한다. Electron 패키지의 런타임 파일 목록에는 넣지 않는다. 이 페이지는 데스크톱 앱 런타임이 아니라 독립 정적 산출물이다.

## 3. 화면 구조

페이지 전체는 클로애드 홈페이지와 같은 인상을 주되 비공개 저장소의 CSS를 복사하지 않고 새로 작성한다.

1. 파란 Luna 제목 표시줄과 최소화·최대화·닫기 장식
2. 간단한 메뉴 표시줄
3. 왼쪽 입력·안내 영역과 오른쪽 미리보기 무대
4. 하단 마스코트 상태 선택 목록
5. 화면 아래 Windows XP 작업표시줄 장식

입력 영역에는 다음 두 필드를 둔다.

- 광고 문구: `textarea`, 최대 120자, 현재 글자 수 표시
- 광고주명: 한 줄 입력, 최대 60자, 현재 글자 수 표시

입력은 `input` 이벤트마다 즉시 반영한다. 저장 버튼은 두지 않는다. 빈 문구는 미리보기를 숨기지 않고 빈 광고판과 검증 안내를 보여 주어 `[광고]` 고정 표기가 사라지는 경로를 만들지 않는다.

미리보기 무대는 선택한 애드워드 애니메이션을 위에, 광고판을 아래에 배치한다. 넓은 화면에서는 입력과 무대를 나란히 두고 작은 화면에서는 세로로 쌓는다.

## 4. 광고판 표시 계약

미리보기는 운영 `src/clawad-ad.html`을 import하거나 복사하지 않는다. 대신 다음 사용자 가시 계약을 독립 코드로 구현한다.

- 3열 2행 Grid
- 1열 첫 행에 고정 `[광고]` 배지
- 문구는 2·3열과 두 행을 사용하며 최대 두 줄
- 둘째 줄 오른쪽은 광고주명·예상 적립 예시·링크 표식이 차지
- 광고주명이 길면 광고주명이 먼저 말줄임되고 적립 숫자는 자르지 않음
- 링크 표식 `↗`와 눌리는 문구의 밑줄
- 패널 배경, 테두리, 라운드, 그림자는 현재 오버레이와 같은 치수 계열 사용
- 실제 오버레이처럼 밝은 화면과 어두운 화면 색상을 지원

예상 적립 값은 레이아웃 확인을 위한 고정 예시다. 클라이언트가 금액을 계산한다는 의미가 없도록 화면에 `레이아웃 예시`라고 명시한다. 광고주 입력값이나 노출 사실에서 리워드를 계산하지 않는다.

테스트는 운영 광고판 HTML과 미리보기 CSS를 함께 읽어 3열 2행, 두 줄 높이, 광고주명 우선 말줄임, `[광고]` 고정 표기 같은 핵심 계약을 비교한다. 색상과 페이지 chrome은 독립 구현으로 유지하며 바이트 일치는 요구하지 않는다.

## 5. 입력 처리

`preview-model.js`는 다음 순서로 표시 문자열을 만든다.

1. 문자열이 아니면 빈 문자열로 처리
2. C0(U+0000–U+001F), DEL(U+007F), C1(U+0080–U+009F)을 공백으로 치환
3. 연속 공백을 한 칸으로 접기
4. 앞뒤 공백 제거
5. 광고 문구는 120자, 광고주명은 60자로 제한

DOM에는 `textContent`만 사용한다. 사용자 입력을 `innerHTML`이나 속성 문자열로 조립하지 않는다. `[광고]`는 입력값과 분리된 정적 마크업이다. 광고주가 `[광고]`를 입력하더라도 시스템 배지로 해석하지 않는다. CLAW-245에서 저장 기능을 붙일 때 서버가 위조 금지 검증을 최종 강제한다.

## 6. 마스코트 목록

마스코트 선택 목록은 한국어 이름과 상태 범주를 가진 정적 manifest로 둔다. manifest는 기존 테마 파일만 참조하며 에셋 복사본을 만들지 않는다.

- 기본: 대기, 생각 중, 확인 필요, 알림, 오류
- 작업: 작업 중, 멀티태스킹, 크런치 모드, 서브에이전트 지휘
- 휴식: 하품, 꾸벅꾸벅, 잠들기, 수면, 기상
- 반응: 매달리기, 화들짝, 하트
- 미니: 미니 대기, 미니 입장, 미니 취침 입장, 옆걸음, 빼꼼, 미니 알림, 미니 기쁨, 미니 수면

각 항목은 버튼으로 렌더링한다. 클릭과 키보드 조작으로 선택할 수 있고 `aria-pressed`로 상태를 알린다. 선택 시 `<img>`의 상대 경로와 대체 텍스트를 갱신한다. 애니메이션을 처음부터 다시 재생할 수 있도록 필요할 때 URL fragment가 아닌 안전한 동일 출처 cache-bust query를 사용한다.

테스트는 `themes/clawad/theme.json`의 `states`, `workingTiers`, `jugglingTiers`, `reactions`, `miniMode.states`를 읽어 미리보기 manifest가 모든 고유 에셋을 한국어 이름과 함께 포함하는지 검사한다.

## 7. 오류와 접근성

- 마스코트 에셋 로드 실패 시 무대를 깨뜨리지 않고 한국어 대체 안내를 표시한다.
- 빈 문구에는 `aria-live` 검증 안내를 표시한다.
- 모든 입력은 실제 `<label>`과 연결한다.
- 마스코트 선택은 `<button>`을 사용하고 focus-visible 스타일을 제공한다.
- 색상만으로 선택 상태를 구분하지 않고 테두리·체크 표시·`aria-pressed`를 함께 쓴다.
- 모션 감소 설정에서는 페이지 chrome 전환 효과를 줄인다. SVG 내부 애니메이션은 기존 에셋의 동작을 유지한다.

## 8. 테스트 전략

새 `test/advertiser-preview.test.js`에서 Node 내장 test runner만 사용한다.

1. 입력 정화와 120/60자 제한
2. HTML에 고정 `[광고]`가 있고 사용자 입력이 `textContent`로만 들어가는지
3. `input` 이벤트가 문구와 광고주명을 즉시 갱신하는지
4. 운영 광고판과 핵심 Grid·두 줄·말줄임 계약이 일치하는지
5. 전체 마스코트 상태가 한국어 이름과 기존 에셋 경로를 갖는지
6. 네트워크·브라우저 저장소 API를 사용하지 않는지
7. 광고 차단기 범용 규칙에 걸리는 `ad` 계열 class/id 토큰을 쓰지 않는지
8. label, button, `aria-live`, `aria-pressed` 접근성 계약

검증 명령은 `apps/client-desktop`에서 `npm test`다. 2026-08-19의 최신 `origin/develop`은 Windows에서 기존 실패 41건이므로, 완료 판정은 새 미리보기 테스트가 모두 통과하고 전체 실패 수가 41건보다 늘지 않는 것이다. 관련 광고판 테스트도 별도로 실행해 회귀 여부를 명확히 본다.

- 광고 금액·리워드 계산
- 테마 원본 에셋과 라이선스
- 비공개 `clawad` 저장소
- CLAW-245의 인증·저장·심사 제출 범위
